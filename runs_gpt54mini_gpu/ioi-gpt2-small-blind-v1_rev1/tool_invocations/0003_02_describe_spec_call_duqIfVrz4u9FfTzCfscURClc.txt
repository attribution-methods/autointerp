# InvestigationSpec — schema reference

Field names below are the only valid top-level keys for `update_spec`. Any other key is rejected at patch time. Enum values are listed at the bottom under "Closed vocabularies".

## Top-level fields

- **`spec_id`** (required, str)
- **`revision`** (optional, int)
- **`parent_spec_id`** (optional, str | None)
- **`prior_results_ref`** (optional, str | None)
- **`revision_reason`** (optional, str | None)
- **`question`** (required, str)
- **`hypothesis`** (required, str)
- **`phenomenon_id`** (required, str)
- **`behavior`** (required, `BehaviorSpec`)
- **`model`** (required, `ModelRef`)
- **`dataset`** (required, `DatasetSpec`)
- **`contrast`** (optional, `ContrastSpec` | None)
- **`stages`** (required, list[`StageSpec`])
- **`success_criteria`** (required, list[`Criterion`])
- **`abort_if`** (optional, list[`AbortPredicate` | str])
- **`max_revisions`** (optional, int)
- **`budget`** (optional, `Budget`)
- **`risks`** (optional, list[str])
- **`status`** (optional, `SpecStatus`)
- **`critiques`** (optional, list[`CritiqueNote`])
- **`approval`** (optional, `Approval` | None)
- **`metadata`** (optional, dict[str, typing.Any])

- **`ToolName`**: `blackbox_probe`, `linear_probe`, `logit_lens`, `direct_logit_attribution`, `activation_patching`, `path_patching`, `attribution_patching`, `sae_inspect`, `steering`, `contrastive_directions`, `attention_heads`, `activation_cache`, `qk_ov_decomposition`
